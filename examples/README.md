# 示例模型

用来演示和测试的模型，都是自己生成的，放这里方便随手拿来跑。

| 文件 | 是什么 | 拿来验什么 |
| --- | --- | --- |
| `cube.stl` | 单位立方体，ASCII STL | 基准：体积必然是 1、表面积必然是 6 |
| `cube.obj` | 同一个立方体，OBJ 格式 | 两种格式应该给出完全一样的结果 |
| `broken.stl` | 立方体少了一个三角形 | 破洞：3 条边界边，修完应该变 0 |
| `torus.stl` | 48×24 的圆环，2304 个三角形 | 真实规模的模型，形状好看，适合截图和演示 |
| `torus.obj` | 同一个圆环，OBJ 格式 | 结果必须和 STL 版逐字一致 |

## 怎么看

```bash
moon run cmd/main examples/torus.stl                    # 体检报告
moon run cmd/main examples/torus.stl --svg torus.svg    # 顺便导出预览图
moon run cmd/main examples/broken.stl --fix fixed.stl   # 修复并保存
```

网页版 <https://mik1e80.github.io/stlkit/> 直接把这些文件拖进去也行。

## 圆环的数验算

R = 0.7（大半径）、r = 0.3（小半径），48 × 24 段。

| 量 | 理论值 | 算出来 | 差 |
| --- | --- | --- | --- |
| 体积 2π²Rr² | 1.2436 | 1.226 | −1.4% |
| 表面积 4π²Rr | 8.290 | 8.252 | −0.5% |

差值是**多边形逼近圆的误差**，不是算错——用 48 段折线代替圆，面积必然偏小。
段数越多这个差越小，所以这两个数反过来也验证了几何计算是对的。
